# Mohd Khizar — Portfolio

Personal portfolio site: data & analytics work at EY, the automation tooling I built there, and applied-AI side projects.

Static site — hand-written HTML, CSS, and vanilla JavaScript. No framework, no build step.

## Structure

```
├── index.html          # The site
├── elements.html       # Style reference page (not linked)
├── assets/
│   ├── css/main.css    # Styles
│   ├── js/main.js      # Scroll animations, counters, lightbox
│   └── Resume.pdf      # Resume
└── images/             # Project screenshots and icons
```

## Run locally

Open `index.html` directly, or serve the folder:

```
python -m http.server
```
